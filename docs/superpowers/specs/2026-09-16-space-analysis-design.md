# Анализ пространства (AI) — дизайн

Дата: 2026-09-16. Статус: одобрено в чате, реализуется.

## Зачем

Пространство копит ретро спринт за спринтом, но никто не перечитывает старые
доски. Одни и те же проблемы всплывают каждый спринт, и команда этого не
замечает. «Анализ пространства» отдаёт последние карточки всех досок
пространства модели DeepSeek и просит найти повторяющиеся паттерны: что снова
хорошо, что снова плохо, что снова стоит улучшить. Результат — обычная доска
особого вида, по которой можно пройтись с командой как по ретро.

Фича есть только у пространств. Это ещё и повод создавать пространства, а не
одиночные доски, поэтому на экране выбора «доска или пространство» это
подчёркивается.

## Решения (зафиксированы с пользователем)

- **Запускать может кто угодно**, у кого есть доступ к пространству (пароль
  введён или его нет). Авторизации на сайте нет и не появится.
- **Лимит: 3 успешных анализа в сутки на пространство.** Общего потолка на сайт
  пока нет: «посмотрим, как будут жечь». Неудачные обращения к модели в лимит
  не входят.
- **Кеш сбрасывает только создание новой доски** в пространстве. Новые карточки
  на старых досках кеш не трогают. Пока новых досок нет, кнопка открывает
  последнюю доску-анализ без обращения к модели.
- **Вход модели: последние 150 карточек**, обход от самой новой доски и самой
  новой карточки, доски-анализы пропускаются, общий бюджет текста 60 000
  символов. Для каждой карточки: текст, тон колонки (`well / bad / improve /
  accent`, из формата доски, поэтому работает для любого формата), название и
  дата доски, счёт голосов (лайки минус дизлайки). Комментарии не передаются.
- **Результат — доска-анализ** с фиолетовой градиентной обводкой, бейджем
  «AI-анализ», названием «Анализ пространства за 16.09.2026» и тремя
  колонками: «Снова хорошо», «Снова плохо», «Снова стоит улучшить». Автор всех
  карточек — «AI-анализ». В конце текста карточки в скобках — в скольких
  досках паттерн встретился.
- **Доска-анализ — обычная доска**: голоса, комментарии, таймер, обсуждение
  работают. Она видна в списке досок пространства. В следующий анализ не
  попадает.
- **Админ пространства всегда админ доски-анализа.** Тот, кто нажал кнопку,
  дополнительно получает обычные права создателя этой доски.
- **Язык** названия, колонок и карточек — локаль того, кто нажал кнопку.
- **Обработка ошибок модели обязательна**: каждая причина отказа получает
  понятное сообщение пользователю и метрику.
- **Ключ DeepSeek не хранится в репозитории.** Только `.env` локально и на
  проде. Ключ, засвеченный в переписке, стоит перевыпустить.

## Хранение: доска-анализ и есть запись

Новых таблиц нет. Доска-анализ — строка в `boards` с `format = 'analysis'`,
своим `creator_token` и `space_id`. Карточки — строки в `cards`, зашифрованы
как все, `author_name` — «AI-анализ» / «AI analysis».

Из этого выводится всё остальное:

- **Кеш актуален**, если у пространства есть доска-анализ, созданная позже
  самой новой обычной (не `analysis`) доски пространства. Тогда action делает
  редирект на неё.
- **Лимит исчерпан**, если досок-анализов пространства с `created_at` за
  последние 24 часа три или больше. Пользователю показывается, через сколько
  часов можно снова (от самой старой из трёх).
- **Параллельные клики** двух людей схлопываются in-memory замком
  `Map<spaceId, Promise<slug>>`: второй ждёт результат первого и редиректится
  на ту же доску. Замок живёт в модуле `analysis.ts`; процесс один.

Отвергнуто: отдельная таблица `space_analyses` (лишняя сущность ради сырого
JSON, который никто не смотрит) и кеш в памяти (сбрасывается деплоем, лимит
обходится рестартом).

## Формат `analysis`

В `board-formats.js`:

```js
{
  id: 'analysis',
  hidden: true,
  columns: [
    { id: 'again_well',    tone: 'well',    title: { en: 'Still good',       ru: 'Снова хорошо' },         short: { en: 'Good',    ru: 'Хорошо' } },
    { id: 'again_bad',     tone: 'bad',     title: { en: 'Still bad',        ru: 'Снова плохо' },          short: { en: 'Bad',     ru: 'Плохо' } },
    { id: 'again_improve', tone: 'improve', title: { en: 'Still to improve', ru: 'Снова стоит улучшить' }, short: { en: 'Improve', ru: 'Улучшить' } }
  ]
}
```

`hidden: true` означает: формат не показывается в выборе на `/new` и в модалке
пространства, `isValidFormat` его **не принимает** (создать такую доску руками
через форму нельзя), `findBoardFormat` и `isValidColumn` работают как обычно
(доска рендерится, карточки в неё добавляются, экспорт работает).
`src/lib/formats.ts` получает `VISIBLE_FORMATS` для пикеров и `ANALYSIS_FORMAT
= 'analysis'`.

Плитка в пространстве считает «настроение» по id классических колонок — для
`analysis`, как и для остальных форматов, полоса пустая. Это существующее
поведение, не меняем.

## Права на доску-анализ

В `src/routes/[slug]/+page.server.ts`: если у доски есть пространство и cookie
`retro_space_creator_{spaceSlug}` совпадает с `creator_token` пространства,
посетитель считается создателем доски (`isCreator = true`, `creatorToken`
доски уходит в страницу, как сейчас). Это касается **всех** досок
пространства, не только анализа: так проще и честнее, админ пространства и
так может удалить любую доску вместе с пространством. `DELETE /{slug}` и
переименование через сокет работают через тот же `creatorToken` доски, поэтому
дополнительных проверок не нужно. Токен пространства в страницу доски не
передаётся.

Тому, кто нажал кнопку, action ставит `retro_creator_{slug}` доски-анализа,
как при обычном создании, и редиректит на `/{slug}` **без** `?admin=`:
админ-баннер для сгенерированной доски не нужен.

## Серверная логика

### `src/lib/server/analysis.ts` — чистая часть, под тестами

- `collectCards(boards, cards, votes, { max: 150, budget: 60_000 })` —
  принимает доски пространства (с форматом и датой), карточки и голоса,
  возвращает список входных записей `{ text, tone, boardTitle, boardDate,
  score }` в порядке «от новой доски и новой карточки», без досок `analysis`,
  не больше `max` штук и не больше `budget` символов текста суммарно. Карточка,
  не влезающая в бюджет, отбрасывается вместе со всеми последующими.
- `cacheState(latestRegularBoardAt, latestAnalysisAt)` → `'fresh' | 'stale'`.
- `analysesInWindow(analysisBoards, now, windowMs)` → число и время самой
  старой в окне (для сообщения «через N ч»).
- `buildPrompt(entries, locale)` — system + user сообщения. Модели говорится:
  найти паттерны, повторяющиеся **в разных досках**, а не в одной; вернуть
  JSON `{ well: [...], bad: [...], improve: [...] }`, где элемент `{ text,
  boards }` (`boards` — число досок, где паттерн встретился, целое ≥ 1);
  не больше 6 элементов в колонке; текст 1–2 предложения на языке `locale`;
  ничего не выдумывать, если данных мало — вернуть меньше элементов или
  пустые массивы.
- `parseAnalysis(raw)` — разбирает строку ответа, валидирует форму, режет
  текст до 2000 символов, `boards` приводит к целому ≥ 1, лишние поля
  выбрасывает. Возвращает результат или `null`. Пустой результат (все три
  массива пусты) — отдельная ошибка `empty`.
- `analysisTitle(date, locale)` → «Анализ пространства за 16.09.2026» /
  «Space analysis for 16.09.2026». `analysisAuthor(locale)` → «AI-анализ» /
  «AI analysis». `cardText(item, locale)` → «{text} (в {n} досках)» /
  «{text} (in {n} boards)». Русские формы числа задаются прямо в модуле:
  `t()` живёт в клиентском словаре, на сервере его нет.

### `src/lib/server/deepseek.ts` — клиент

`analyzeWithDeepSeek(messages, { apiKey, apiBase, timeoutMs: 60_000 })`:
`POST {apiBase}/chat/completions`, `model: 'deepseek-chat'`,
`response_format: { type: 'json_object' }`, `temperature: 0.3`,
`max_tokens: 2000`. Возвращает строку `choices[0].message.content`. Бросает
типизированную ошибку `DeepSeekError` с `kind: 'network' | 'timeout' | 'http'
| 'shape'` и статусом. Ключ и текст карточек в логи не попадают.

Конфигурация через `$env/dynamic/private`: `DEEPSEEK_API_KEY`,
`DEEPSEEK_API_BASE` (по умолчанию `https://api.deepseek.com`).

### Form action `analyze` в `src/routes/spaces/[slug]/+page.server.ts`

Порядок:

1. Доступ к пространству: если у пространства есть пароль — нужна cookie
   `retro_space_{slug}` или cookie создателя пространства; без пароля —
   доступ у всех. Иначе `error(403)`.
2. Ключ не задан → `fail(503, { analysis: 'not_configured' })`.
3. Кеш `fresh` → редирект на последнюю доску-анализ.
4. Лимит исчерпан → `fail(429, { analysis: 'limit', retryInHours })`.
5. Карточек нет (после `collectCards`) → `fail(400, { analysis: 'no_cards' })`.
6. Замок на пространство: если анализ уже идёт — дождаться и редиректнуть
   на его доску.
7. Вызов модели. `DeepSeekError` → `fail(502, { analysis: 'network' |
   'timeout' | 'http' })`. `parseAnalysis === null` → `fail(502, { analysis:
   'bad_response' })`. Пустой результат → `fail(422, { analysis: 'empty' })`.
8. Транзакция: вставить доску (`format: 'analysis'`, `spaceId`, новый
   `creatorToken`, заголовок по локали), вставить карточки по колонкам с
   автором и текстом по локали. `lastFormat` пространства **не** трогаем.
9. Cookie `retro_creator_{slug}`, метрика `retro.analysis.created`,
   редирект 303 на `/{slug}`.

Метрики: `retro.analysis.requested`, `.cached`, `.created`,
`.failed.{not_configured|limit|no_cards|network|timeout|http|bad_response|empty}`.
Лог pino: событие, slug пространства, число карточек на входе, длительность
вызова, вид ошибки. Без содержимого.

Локаль приходит скрытым полем `locale` формы, как в `createBoard`.

## Интерфейс

- **Кнопка «Анализ пространства»** (`space.analysis.button`): на странице
  пространства рядом с «Новая доска» в шапке-заголовке; на странице любой
  доски, у которой есть пространство, в шапке рядом с кнопкой «Поделиться»
  (на мобильных — пункт в меню «⋯»). Это форма `method="POST"
  action="/spaces/{slug}?/analyze"` с `use:enhance`, скрытое поле `locale`.
  Во время запроса кнопка заблокирована, текст «Анализируем…», рядом спиннер;
  ожидание может быть 10–40 секунд, поэтому под кнопкой подпись «Обычно до
  минуты». Ошибка из `form.analysis` выводится под кнопкой текстом по ключу
  `space.analysis.error.{kind}`, для `limit` с подстановкой часов.
- Если ключ не задан (`analysisEnabled: false` в `load` пространства и
  доски), кнопка не рендерится.
- **Доска-анализ**: контейнер колонок обёрнут в рамку с фиолетовым
  градиентом (`padding-box / border-box` двойной фон, чтобы градиент шёл по
  обводке, скругление как у доски), в шапке вместо бейджа формата — бейдж
  «AI-анализ» (`analysis.badge`) с тем же градиентом. Тёмная тема — те же
  токены, чуть приглушённее. Цвета — новые токены `--ai-from`, `--ai-to` в
  `app.css`.
- **Плитка в пространстве**: та же градиентная обводка и бейдж «AI-анализ»
  в правом верхнем углу (бейдж «Live now» при этом остаётся, если доска
  открыта); сортировка и поиск не меняются.
- **`/new`**: в карточке «Пространство» под описанием строка с градиентным
  бейджем «AI» и текстом «Анализ паттернов по всем ретро» (`new.space.ai`).
  Карточка «Доска» без изменений.
- Все строки — в `en.json` и `ru.json`.

## Тесты

Юнит (`src/lib/server/analysis.test.ts`, `src/lib/formats.test.ts`):
- `collectCards`: порядок от новой доски и карточки; пропуск досок
  `analysis`; лимит 150; бюджет символов режет хвост; тон берётся из формата
  доски; счёт голосов.
- `cacheState`: нет анализа → stale; анализ новее последней доски → fresh;
  новая доска после анализа → stale; пространство без обычных досок → stale.
- `analysesInWindow`: считает только в окне и возвращает самую старую.
- `parseAnalysis`: валидный JSON; мусор → null; лишние поля отбрасываются;
  длинный текст режется; `boards` нормализуется; пустой результат.
- `buildPrompt`: содержит все карточки, тон и локаль.
- Формат `analysis`: `isValidFormat('analysis') === false`, `findBoardFormat`
  его находит, `VISIBLE_FORMATS` его не содержит.
- Тест целостности словарей ловит недостающие ключи.

E2e (`e2e/analysis.spec.ts`): Playwright поднимает вторым `webServer` мок
`e2e/mock-deepseek.mjs` на порту 4778, отвечающий детерминированным JSON;
приложение получает `DEEPSEEK_API_BASE=http://localhost:4778` и
`DEEPSEEK_API_KEY=test`. Мок переключается в режим ошибки заголовком или
эндпоинтом `/__mode` для сценария отказа. Сценарии:
1. В пространстве с двумя досками и карточками клик создаёт доску-анализ с
   тремя колонками, карточками от «AI analysis» и бейджем; доска видна в
   списке пространства с обводкой.
2. Повторный клик без новых досок открывает ту же доску (slug совпадает).
3. Создание новой доски, затем клик — новая доска-анализ.
4. Четвёртый запуск за сутки показывает сообщение о лимите (три успешных
   анализа получаются через три новые доски).
5. Мок в режиме ошибки — сообщение об ошибке, доска не создаётся.
6. Пустое пространство — сообщение «нет карточек».
7. Создатель пространства в новом контексте по admin-ссылке пространства
   открывает доску-анализ и видит пункт «Rename board» в меню.
8. Кнопка есть на странице доски внутри пространства и отсутствует на
   одиночной доске.

## Вне рамок

Общий потолок запросов на сайт, история анализов в отдельной таблице,
передача комментариев модели, повторный анализ по кнопке без новых досок,
выбор модели или провайдера, стриминг ответа.
